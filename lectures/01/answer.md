# 第1回 解答

## 演習

- 講座に固有の質問（宿題の3レベル）へのモデルの回答：LoRAについて質問すると、大規模言語モデルを効率的に追加学習する手法だと説明された。一方、宿題の「3レベル」について質問すると、講座独自の定義ではなく、一般的な難易度区分などを推測して回答した。
- 用語集の正しい意味と比べて気づいたこと：用語集によると、宿題の3レベルは「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」の3段階であり、どれか1つに取り組めばその回の宿題は完了する。モデルは自然で詳しい回答を生成したが、講座独自の定義とは異なっていた。回答がもっともらしくても正確とは限らないため、用語集などの資料と照合する必要があると分かった。
- 表示できたトークン数（入力 / 出力）：LoRAの質問は7 / 651、宿題の「3レベル」の質問は初回21 / 719。

## 宿題

- 取り組んだレベル：基礎
- やったこと：同じ質問「AIE2026の講座の宿題にある『3レベル』とは何ですか？」を、gemini-3.5-flash-lite と gemini-3.8-flash でそれぞれ3回実行し、回答内容とトークン数を比較した。
- 結果：
  - gemini-3.5-flash-lite：入力21、出力719 / 519 / 512トークン。
  - gemini-3.8-flash：入力21、出力713 / 673 / 688トークン。
  - 両モデルとも講座独自の定義を正しく回答できず、一般的な難易度区分などを説明した。出力トークン数はモデル間・実行回間で異なった。
- 気づき・疑問：同じ質問でも、モデルによって回答の説明や表現が異なり、同じモデルでも出力の長さが変化した。しかし、出力が長いことが回答の正確性を意味するわけではなかった。今回の結果から、モデルの回答をそのまま信じるのではなく、用語集などの信頼できる資料で確認することが重要だと考えた。ただし、今回の実験だけでは、回答が変化した原因やモデル間の一般的な性能差までは判断できない。
